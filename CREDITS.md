# Credits and Attribution

This repository is an unofficial community fork/continuation of the Lucid Blocks
co-op mod. It is not the original Lucid Blocks game and is not affiliated with or
endorsed by the Lucid Blocks developers/publisher.

## Upstream Mod

- Original community co-op mod repository: https://github.com/parkers0405/lucid-blocks-coop
- Original mod author / forum handle: Parker Settle / Mr_Settle

The work in this repository is focused on packaging cleanup, dedicated-server
experiments, multiplayer fixes, documentation, and splitting features into
separate mod packages. We do not claim authorship of the original co-op mod.

## Lucid Blocks

Lucid Blocks belongs to its original developers/publisher. This project is an
unofficial mod and requires a legally owned copy of the game.

## Assets Not Cleared for Public Core Releases

Fan/test avatars or character assets such as Pim, Charlie, and Mr. Frog should
not be shipped as part of the public core package unless their rights are cleared.
If kept for private testing, they should be moved to a separate private addon or
removed from public release archives.
